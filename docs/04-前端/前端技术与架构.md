## 五、客户端架构（桌面 + 手机）

**双端独立**：零共享业务实现；共享 = 协议类型 + golden + design token（§十二、`cross-platform-frontend.mdc`）。

**手机 = 桌面 − Electron/OS 能力**（黑名单减法）：保留云端聊天/协作/审批/成本/IM；减去本地文件、stdio MCP、托盘、热键、静默更新、sidecar。**否决** RN、纯 PWA。传输 = web SPA → Capacitor；Android WebView origin `https://localhost` 须进 CORS；无 Firebase 不得 `PushNotifications.register()`。→ `apps/mobile/`。

**桌面价值**（vs Web）：后台常驻 + 通知、热键、本地文件、本地 MCP。**否决** PWA / 全原生 / Tauri（备选）。

**主进程**：renderer 本地加载；SSE 直连后端或经 sidecar `/v1/inference`（不经 IPC）。✅ local-store 只读离线；✅ outbox 回写器（主进程耐久，renderer 退出 HTTP 回写）；✅ sidecar recovery/attach。⏳ `connection-manager` / `mcp-pool`。边界 → [双模式 §10.3 / §10.7](/docs/02-架构/双模式工作区.md)。

**跨端策略**：**否决**共享实现核、一棵树降级。红线 = fold 必过 `pnpm conformance`；契约只走后端单一源。域卡片各端重建。

## 十、SSE 与协议一致性

入口：`services/sse/dispatch.ts`（单一分发）；传输/重连在 `streamConversation.ts`。事件语义 → [SSE 事件与录制回放](/docs/03-AI核心/SSE事件与录制回放.md)。

**约束**：发送即有流（POST 恒 SSE；`turn_queued` EPHEMERAL）；Store 最小更新；乐观发消息；⏳ `reconcileAllRuns` 未实现。

**打开对话水合**：先云消息窗 → `loadRecovery`。本地事实（sidecarLive / unsynced）→ 投影 + attach，**不调** `resolveSidecarRoot`、不走云 attach。无本地事实 → 云 `attachOnOpen`。→ [双模式 §10.7](/docs/02-架构/双模式工作区.md)、[运行时三模型 §8.3](/docs/03-AI核心/运行时三模型与挂起.md)。

**conformance**：`fold(events)→ProjectedTurn` 纯函数；后端 oracle 裁判；`pnpm conformance`。向量 = 手写 builder + 录制裁切并存。纪律 → `protocol-conformance.mdc`。

**离线预览**：`#/preview` 经真实 dispatch 回放；**否决** Storybook / 手写 mock。e2e：Playwright + webapp 壳 + 向量 SSE；**否决** `route.fulfill`。→ `frontend-preview.mdc`。
