# 前端成本呈现

> 后端不变量 → [成本配额与计费](/docs/05-平台与运维/成本配额与计费.md)。本文只记 VIEW 层决策。数据：`services/usage.ts`、`stores/usage.ts`、`lib/format.ts`、`RunNode.{cost,usage}`。

## 信息分层

**无粒度开关**（`usageDetail` 已下线）——恒展示，靠位置分层：inline 只做信号（¥+token 摘要）；详情进面板。诊断模式 ⊥ 用量。→ `UsageSettings.tsx`、`RunDetailBody.tsx`。

## 格式化

金额整数 nano-CNY；展示元 = nano/1e9（`cny_total` 已是元）；API 不再下发汇率。0 成本显「—」，绝不「¥0.00」；<1 分显「<¥0.01」。

## 三级呈现

| 层 | 位置 | inline | 详情 |
|---|---|---|---|
| 回合 | 气泡 meta / 状态条 | ¥ + Agent 数 + 轮次(>1) | token 拆分 |
| run | run-detail「资源消耗」 | 该 run ¥ | model/三价/token；**默认展开** |
| 账户 | 用量页 | 额度条 + 近 7 日趋势 | 明细恒显 |

图节点 face **不显钱**（仅用时·工具）；**否决** face 叠 ¥。对话累计 caption **已退役**（零噪音）。多 Agent：¥ 归状态条；token/轮次补气泡 meta（不重复 ¥）。

## BYOK

估算一律「≈¥」+「估算」标注；`unpriced` 出「—」且必挂「自带密钥·未计价」（防误读免费）。记账与估算**永不相加**。`byok 分支 = billing_mode==="byok"`（平台代付休眠时走 token/估算面）。

## 配额拒绝

429 按 code 分流：`QUOTA_EXCEEDED` 不重试（可次级 CTA 去设置接 Key）；`RATE_LIMITED` 可重试。文案以后端 `message` 为单一来源。→ `lib/errors.ts`。
