## 内容架构（防漂移地基）

正文 = **结构化内容源**（`pages/toolbox/manual/content/*.ts`，纯数据 block，无 JSX），由通用渲染器（`BlockRenderer` / `ChapterRenderer`）消费：

- **节 ID 注册表**：`sectionIds.ts`（功能现场深链 / JumpLink 共用）；路由常量：`paths.ts`（手册内禁止手写路由字符串）。
- **侧栏目录与全文搜索**（标题 + 正文 + FAQ 问句）均从内容源派生，无第二真相源；命中显示节标题 + 上下文摘要。
- **真组件嵌入**：embed block 存字符串 key → `embedRegistry.ts` 懒加载真组件（协作图 Hero / 机制场景 / 辩论室记分牌·终审 / 检查点拍板卡预览，预览件在 `manual/embeds/`）。
- **门禁测试**（vitest，`manual/__tests__/`）：术语 lint（内容源禁用术语表退役词）、路由/锚点校验（`go`/`jump` 链接与 settingsRows 的 `to` 必须指向真实路由与真实节 id）、embed key 必须在注册表可解析。
- **截图冒烟**：`pnpm -C apps/desktop shoot:manual` 四章代表场景（含真图与嵌入预览）。

## 维护约定

- **用户向正文**：改 `pages/toolbox/manual/content/*.ts`（内容源），不要往渲染器里写死文案。
- **机制 / 契约**：改 `docs/03`–`05`；手册只加用户能懂的一句 + 深链。
- **新功能上线检查清单**：reference 是否需补 FAQ / 能力状态标注？「即将上线」的能力落地后改状态；术语与路由由门禁测试自动兜底。
- **功能页新增 ? 入口**：统一走 `components/ManualHelpLink.tsx` 登记深链。
