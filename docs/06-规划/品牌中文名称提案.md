## 二、命名标准

### 必要条件

1. **四字**：符合中文品牌四字格传统，节奏完整
2. **顺口**：声调起伏自然，连读不拗口
3. **有气势**：念出来有力量感或画面感，不平淡
4. **可注册**：不与已有知名品牌重名（需后续核查）

### 加分项

| 维度 | 说明 |
|---|---|
| 产品契合 | 暗合"多 Agent 协作"核心差异点 |
| 意象鲜明 | 听到就有画面，不需解释 |
| 中英呼应 | 与 AgentCore 有某种语义或气质关联 |
| 延展性 | 可衍生子品牌（XX 开放平台、XX 生态等） |

## 四、声韵分析（顺口 + 气势排序）

好名字的声韵规律：
- **声调起伏**：避免连续同调（尤其连续去声），有升降变化更有节奏感
- **韵母多样**：不同韵母交替，不重复闷住
- **收尾有力**：末字去声或阳平收尾比上声更干脆

| 排名 | 名称 | 声调走势 | 分析 |
|---|---|---|---|
| 🥇 | **星核聚变** | 1→2→4→4 | 从轻到重层层递进，像蓄力爆发；四个韵母全不同（ing/e/ü/ian），零拗口；念完有"砰"的收束感 |
| 🥈 | **智潮涌动** | 4→2→3→4 | 起伏如浪，"潮涌动"后鼻音共鸣浑厚；念出来有气场，适合喊口号 |
| 🥉 | **群思跃迁** | 2→1→4→1 | 声调交替最丰富，"跃迁"干脆有力；但"群思"略学术 |
| 4 | **灵犀共振** | 2→1→4→4 | "灵犀"入口流畅，"共振"收尾有力；整体节奏好 |
| 5 | **众智涌现** | 4→4→3→4 | 意义最佳但开头"众智"两个 zh+去声连击略绊 |
| 6 | **万象协同** | 4→4→2→2 | "万象"开口有气势，但"协同"收尾偏软，像在念公文 |
| 7 | **智涌星河** | 4→3→1→2 | 最流畅，但先沉后扬偏柔美，气势不足 |

### 第一梯队推荐

**星核聚变** — 综合最优
- 顺口 + 气势 = 全场最佳
- 意象鲜明：恒星内核聚变，一听就有画面
- 产品隐喻到位：多个 agent（核）聚合产生质变（聚变），暗合"协作涌现"
- 与 AgentCore 的 "Core"（核）有语义呼应
- 辨识度高，不易与其他科技品牌混淆
- 可衍生：星核生态、星核开放平台、星核社区

**众智涌现** — 语义最精准
- "涌现"（emergence）是多 agent 系统的学术核心概念
- 直接传达"集体智慧产生超越个体的效果"
- 但声韵略逊，开头稍拗口
- 适合追求"学术正统 + 理念传达"的路线

**群思跃迁** — 平衡之选
- "群"直接点题 multi-agent，"跃迁"有量子力学的科技感
- 声调交替丰富，念起来有节奏
- 介于"好念"和"有内涵"之间的折中
