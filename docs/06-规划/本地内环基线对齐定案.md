# 本地内环基线对齐定案（2026-07-23）

> **状态**：已拍板（承 A+B A1+/A2′）。  
> **谁用 / 问题 / 呈现**：开发者绑本地仓 + sidecar 改代码时，要与云端同款「查看改动 / 回退到本回合开始」；现状仅工具参数预览。

## 目标

| 项 | 目标 | 非目标 |
|---|---|---|
| 基线 | sidecar 回合开始 best-effort 本地基线 | 不阻断回合；大仓超限 skip |
| 可审 | 「查看改动」真 before/after（相对基线） | 不做预写暂存 |
| 回退 | 「回退到本回合开始」恢复本机基线 | 非整仓 OSS 上传当基线 |

## 关键取舍

1. **主路径 = sidecar 本机**（文件不经云遥控）；云端 A1+/A2′ 不动。
2. **基线落点**：工作区旁 `.agentcore/baselines/`（或同等本机路径），不强制上传云 snapshot（避免大仓上行）。
3. **读侧**：优先桌面 / sidecar 本机 diff·restore；若必须经 API，只传 id/元数据不传全树 zip。
4. **门闩**：文件数 / 体积 / 耗时上限——超限 skip 基线 → 降级 A1 工具预览（与云失败同口径）。
5. **明确不做**：默认预写暂存、git push/PR、LSP、照搬 Cursor rules、手机一期。

## 验收

- sidecar 样例仓：有基线时「查看改动」出真 diff +「回退」可恢复；超限 / 失败降级工具预览。
- 云端路径回归不破。
- 单测覆盖门闩与 skip。

## 落地顺序

1. sidecar 打基线 + 持久化引用 → 2. 本机 diff / restore 接缝 → 3. 桌面 `TurnFileChangesReview` 接本地

## 接缝（落地）

- **打基线**：sidecar `_run_turn` 在 `message_id` mint + `outbox.begin_turn` 之后、`run_chat_pipeline` 之前调用 `maybe_capture_turn_baseline(..., location=local)`；落点 `.agentcore/baselines/{message_id}.zip`（超限/超时 skip → A1 预览）。resume 不重打。
- **读/回退**：桌面 `location===local` → sidecar RPC `turnFilesDiff` / `restoreTurnBaseline`（本机 live zip vs 基线 zip / `unzip_into`）；云端仍走 REST + `restore_snapshot`。复用 wire 字段 `baseline_snapshot_id`（本机约定 id = message_id，无新字段）。
