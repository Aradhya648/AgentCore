# AgentCore 文档索引

设计文档总入口。`01` → `05` 为公开主题分组，无强制阅读顺序。跨工具 AI 最短入口 → [`AGENTS.md`](/AGENTS.md)。

> **定位**：公开仓 `docs/01`–`05` = What/Why（给人 + AI）。本地 `.cursor/rules/` = How（gitignore，贡献者可不读）。
>
> **⏳ 未落地蓝图**：可出现在 `01`–`05`；以**代码与文内短指针**为准。详细提案 / 讨论全文**不在公开仓**（维护者本地可有 `docs/06-规划/`，勿依赖 clone 里存在该目录）。
>
> **禁搜**：产品 `trace_id` / `conversation_id`（含 32 位 hex）**禁止**在文件系统或 `agent-transcripts/` 里搜——查法见本地 `.cursor/rules/conversation-logs.mdc`（正文只在该 rule，此处不复述）。
>
> **贡献 / 安全**（人类贡献者）：[CONTRIBUTING.md](/CONTRIBUTING.md) · [SECURITY.md](/SECURITY.md)
