# 产品公告文案模板

运营发「产品公告」（Admin Notice / Banner + Modal + IM 官方号）时套用；**勿每次现编结构**。发布命令 → `pnpm publish:notice`（`deploy/scripts/publish-product-notice.mjs`）。

字段默认：`severity=high` · `surface=both` · `dismiss_policy=once`。维护窗可把 `dismiss_policy` 改为 `never`。政策/额度类用 `surface=modal`（仅 `dismiss_policy=once`）。

## 1. 后端短更新（热修 / 无感或近无感）

**标题**：`系统更新 · 约 {HH:MM}`

**正文**：

```text
我们将于今天 {HH:MM}（约）进行一次后端更新，预计 1–3 分钟。

期间：极少数进行中的对话可能短暂卡住或需点「重试」；更新完成后刷新即可继续。
本次：{一句话变更摘要；多条用「；」分隔，勿贴 commit hash}

无需重装客户端。若结束后仍异常，打开消息页「AgentCore 官方」或稍后重试。
```

**适用**：只发 `pnpm deploy:backend`、无桌面/手机发版。

## 2. 全端发版（含桌面 / 手机）

**标题**：`版本更新 · {桌面版号或「新版本」}`

**正文**：

```text
新版本将于今天 {HH:MM} 起陆续上线。

桌面：应用内检查更新，或官网重新下载安装。
手机 / Web：刷新或打开应用商店/官网安装包即可。
本次亮点：{≤3 条用户能感知的变化}

更新过程可能短暂不可用；完成后按上面方式升级即可。
```

## 3. 计划维护（较长中断）

**标题**：`维护通知 · {HH:MM}–{HH:MM}`

**正文**：

```text
计划维护窗口：今天 {开始}–{结束}（约 {N} 分钟）。

维护期间无法登录或发送消息。窗口结束后自动恢复，无需重装。
原因：{一句话，如「数据库迁移 / 证书轮换」}
```

建议：`dismiss_policy=never`，并设 `end_at` 为窗口结束后约 30 分钟。

## 4. 政策 / 额度变更（必读弹窗）

**标题**：`{政策或额度主题} · 生效 {日期或「即日起」}`

**正文**：

```text
{一句话说明变更是什么、对用户有何影响}

生效：{日期 / 即日起}
详情：{可选 CTA 文案，如「查看完整说明」}
如有疑问，打开消息页「AgentCore 官方」查看本条归档。
```

**字段**：`surface=modal` · `dismiss_policy=once`（不可 `never`）· 建议 `severity=normal` 或 `high`。首次 publish 会同步写入 IM「AgentCore 官方」。

**适用**：配额调整、计费政策、服务条款更新等需用户登录后确认一次的通知。

## 填写清单（发之前勾）

- [ ] 时间用用户本地习惯（北京时间），写清「约」
- [ ] 摘要写**用户能感知的事**，不写内部文件名 / SHA
- [ ] 热修用模板 1；有桌面 bump 用模板 2；政策/额度用模板 4（`surface=modal`）
- [ ] 发完自检：桌面顶栏 Banner / 登录弹窗 / IM「AgentCore 官方」对应 surface 能看到
- [ ] 部署完成且验收通过后，可在 Admin 归档本条（可选）
