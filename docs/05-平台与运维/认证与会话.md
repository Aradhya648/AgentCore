# 认证与会话

> ✅ Phase 1–2 已落地（刷新宽限 + 前端单飞；桌面 `app://` 跨站 cookie；CSRF HMAC 强制；Bearer 手机豁免）。⏳ 找回密码。
> → `apps/server/agentcore/auth/`、`api/routes/auth.py`

## 一、设计基线

| 维度 | 选择 | 理由 |
|---|---|---|
| 登录标识 | 用户名 + 密码 | `email` 可空，留作找回/OAuth |
| 令牌传输 | httpOnly Cookie | JS 拿不到明文；SSE/fetch 天然带 |
| 令牌载体 | access（短）+ refresh（长，path 限 auth） | 减小 refresh 暴露面 |
| 密码哈希 | argon2id | 规避 passlib+bcrypt≥4.1 坑 |
| 注册 | 开放（`REGISTRATION_OPEN` 可关） | 被否：邀请码——摩擦大；滥用靠限流+admin 停用 |
| 暴力破解 | 5 次锁 15min | |

客户端注册须勾选年满 18 + 协议/隐私。Schema 真相源 = ORM + alembic。

## 二、数据模型

四表 → `db/models/auth.py`、`users.py`：`users` / `credentials` / `invites`（遗留 deprecated）/ `refresh_tokens`（只存哈希）。密码与 refresh 均不可逆；建模约定见 [核心接口 §6.2](/docs/02-架构/核心接口定义.md)。

## 三、令牌模型

| 令牌 | 形态 | 生命周期 |
|---|---|---|
| access | 无状态 JWT（HS256；`fam`=token_family） | 默认 30min |
| refresh | 不透明随机串（库存 SHA-256） | 默认 30d 滑动 + 族绝对上限（默认 90d；admin audience 默认 24h） |

access 纯本地解码；无效一律 401。会话元数据写在 `refresh_tokens`；终态行 GC（默认保留 7d）。

## 四、端点契约

`POST /v1/auth/{register,login,refresh,logout,change-password}` + `GET/PATCH/DELETE /me` + 会话管理；头像在 `/v1/users`。字段 → OpenAPI / `api/schemas/auth.py`。

**决策语义**：login 401 不区分账号是否存在；非属主会话 → 404；`revoke-others` 无 `fam` 旧 access → 422（不选 revoke-all 防误踢自己）。改密吊销全部 family、当前会话重发 Cookie。注销：软删+匿名化+跨域清理（对话/分享/BYOK/头像）；账本保留。

**头像**：独立 `AssetStorage`；内容寻址键 + `?v=<hash>`；取图公开（`<img>` 不带 Cookie）；上传需 `AuthUser`。

**Bearer（手机）**：`/v1/auth/token*` 返明文、不设 Cookie。Capacitor Android origin = `https://localhost`——生产 CORS 必须含之（及 `capacitor://localhost` / `http://localhost`）。注入：`AuthUser` / `OptionalUser` / `AdminUser`。

## 五、刷新轮换 + 重用检测

| 场景 | 行为 |
|---|---|
| 首次交换 | 标 `rotated_at`、同 family 签发后继 |
| 已 rotated 在宽限窗（默认 10s）内再现 | 善意并发 → 补发、**不撤销** |
| 超窗 / 已 revoked 再现 | 吊销整个 family |
| 过期 | 拒绝 |

前端单飞刷新（renderer + 主进程协调）。刷新三态：`renewed` / `auth_dead`（仅 401/403）/ `transient`（网络/5xx → **不踢登录**）。AuthGate：`loading` / `unavailable` / `unauthenticated`。

## 六、静默刷新约束

401→刷新→重试对用户无感。**流式通道须各自接入**（聊天 SSE 常绕过统一封装）；新增绕过统一层的 fetch 通道同理。

## 七、Cookie / CSRF 易踩坑

- **refresh path**：生产反代 `/api/` → `COOKIE_PATH_PREFIX=/api`，否则 cookie 不回传。
- **生产桌面**：`SameSite=None` + `Secure`（`app://` 跨站）；启动 fail-closed（none 而无 Secure → 拒启）。SameSite **不**提供 CSRF 防护。
- **CSRF**：无状态 HMAC（`sign_csrf_token`），**勿改回服务端存储**（热重载/多 worker 会清空 → 403 CSRF_FAILED）。纯 Bearer 且无 access cookie → 豁免。
- **主进程 outbox**：纯 Bearer、`credentials:omit`；写回 cookie 须按 API URL 推 SameSite/Secure，refresh 须带 `expirationDate`。
- **CORS**：`CORS_ALLOW_ORIGINS` 逐源；含 `app://agentcore` + 手机 Pages + Capacitor localhost。

排障：「总掉登录」先查刷新链路，勿只调长 access TTL。桌面日志 `userData/logs/desktop.jsonl`：`auth.bootstrap` / `auth.session_kicked` / `auth.refresh`。

## 八、IDOR（全库权威）

| 决策 | 内容 |
|---|---|
| 作用域 | 受保护资源按 `user_id` 过滤 |
| 失败 | 非属主 → **404** |
| 仓储默认（SEC-002） | per-user 聚合 `get_by_id`/mutate **`user_id` 必填**；跨 owner 仅显式 `*_unscoped()` |

IM 同理：非 `chat_members` → 404。其它文档只交叉引用本 §。

生产必改：`jwt_secret_key`；`cookie_secure`；跨站须 `cookie_samesite=none` + `secure=true`。→ `config/`、`.env.example`。
