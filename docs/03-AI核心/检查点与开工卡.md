# 检查点与开工卡

> **权威**：`ask_user` 开工提案卡、`team_preview` / `plan_review` / `stage_card`。挂起机制 → [运行时三模型](/docs/03-AI核心/运行时三模型与挂起.md)；编排字段 → [编排器](/docs/03-AI核心/编排器与CEO主Agent.md)；前端卡 → [协作图 UX](/docs/04-前端/协作图与双视图UX.md)。

## 一、`ask_user` 开工提案卡

开场引导是 `ask_user`（CEO 唯一发问原语）的**内容形态**，非独立工具。对「能做但用户没说全」的产出类请求：复述目标 + 起步计划 + 少数高杠杆决策——想省事一键开做，想管就地调。

**影响力分档**（非「是不是技术」）：

| 档 | 字段 | 语义 | 上限 |
|---|---|---|---|
| 起步计划 | `assumptions` | 影响小、可逆；只读陈列 | 10 |
| 重点问题 | `questions` | 高杠杆；**每个预填 `default`**（防问题墙） | 5；选项 ≤6 |
| 风格基调 | `style_options` | 仅视觉类（网站/海报） | 6 |
| 交付形态 | `format_options` | 演讲/PPT：pptx / marp / outline；**Agent/自动化**（定案甲）：可运行自动化 / 控制台原型 / 仅方案 | 6 |

建站：`style_options` 强制非空 + resume 结构化记账；无记账拒 `build_website`（`command=auto` 窄豁免）。演讲：`format_options` 强制；已选 pptx 时禁静默只交 `.md`。

**Agent / 自动化 vs toolshed（定案甲；乙 playbook 二期）**：

- 窄意图（做/打造/生成 + Agent|自动化|工作流|流水线，或明确多步骤代运营）→ 开工卡**必须**非空 `format_options` 三档；无记账拒 `delegate`。
- 选**控制台原型** → 才允许 `build_toolshed`（再走既有风格闸）。
- 选**可运行自动化** → 禁止默认 toolshed；自由组队 / `build_feature`；无执行环境如实降级交付。
- 选**仅方案** → 不进 toolshed/website 硬锁流水线。
- 勿误伤「用团队做调研」「写 agent 提示词」。纯「做控制台/官网」仍走现 website/toolshed 闸。

→ 见代码: `runtime/runs/website_style.py`、`presentation_format.py`、`automation_delivery.py`

**统一机制**：开场味 / 途中味 = 内容差，不是两套工具；`blocking`（默认 true）= 模型真语义判断。「该结束还是挂起」归运行时。`blocking=false` 须写明将采用的默认，否则拒调。阻塞检查点 = 挂起即收口，冷路 `POST …/resume`。

**何时不用**：简单问答直答；需求已全 → 直接 `delegate`；意图都复述不出 → 先普通文字问清，不出卡。

**否决**：开场问题墙；`kickoff` + `ask_user` 两工具。

## 二、检查点与团队预审

| 原语 | 触发 | 语义 |
|---|---|---|
| `ask_user` | CEO 关键岔路 | CEO 工具效应 |
| `plan_review` | step 标 `checkpoint_after` | 波间结构挂起；前置强制 CEO 把关摘要 |
| `team_preview` | `delegate`/`debate` fan-out 前 | 计划确认 ∪ 能力授权（公共 kickoff gate） |

**delegate 卡**：≥2 worker 或辩论标记，或本地 `command=kickoff` 需能力授权 → 挂卡。动作：授权并开工（可嘱咐）/ 停止。  
**debate 卡**：顶层一律弹；动作：授权开赛（可嘱咐）/ 停止。`research_first` 键已退役（庭前取证内化）→ [辩论编排](/docs/03-AI核心/辩论编排设计.md)。

**阶段推进卡 `stage_card`**：幕间一步授权（如「按此开辩」= 机制直起、`skip_kickoff`）。**否决**二步制与「发消息即 orphan」。→ 见代码: `runtime/kickoff/stage_card.py`

**跳过**：单 worker+`finalize`；同回合已有阻塞 `ask_user` 已确认；含 `checkpoint_after` 时计划半边让位；`team_kickoff=skip` 放行两半边；嵌套/`light`/续跑不挂。`team_kickoff=always` 在仍该挂的场景总挂。

**专用卡**（`card` 参数，不新增 kind）：`proposal_pick` / `risk_ack`；主拍板四选一通则在提示词层。权限三轴 → [安全 §三](/docs/05-平台与运维/安全权限与治理.md)。`plan_review`/checkpoint **不受**三轴影响。
