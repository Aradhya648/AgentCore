# 运行时三模型与挂起

> **权威范围**：Interaction / Turn Journal / Run 三模型、端口契约、一轮一网关。入口 → [执行引擎](/docs/03-AI核心/执行引擎架构设计.md)。

依赖：Interaction 最小独立；Journal 是 Run 的地基；Run 落在两者之上。

## Interaction（唯一挂起原语）

收编审批 / `ask_user` / 本地工具 / `plan_review` / `team_preview` / 委派授权 / 阻塞升级 / 逐轮辩论 / `stage_card`。热路 `POST …/interactions/{id}`；冷路 `POST …/resume`。`delegation_authorization` **半退役**（并入开工卡；kind 保留回放）。

| 决策 | 取值 |
|---|---|
| pending 真相源 | journal fold；**否决**新建 `interactions` 表 |
| 不答语义 | 默认无限等待；废除静默 auto-DENY / 超时回落 |
| orphaned | turn 终了 / sweeper / resolve 410 / abort·retry·stop；**断连 ≠ 失效** |
| 同对话并发 | 见下节 [同对话再发](#同对话再发steer--queue)；热挂起→409；冷 paused 可发消息 |
| 跨端 | 补齐客户端；**否决**后端按客户端能力降级 |

⏳ 跨进程等待（Redis BLPOP）。

## 同对话再发（Steer / Queue）

用户在同对话再发消息的三种意图（**已定案**；P0 ✅ · P1 ✅）：

| 原语 | 意图 | 入口（产品） |
|---|---|---|
| **Steer** | 软插入当前回合，不硬停 | 默认 Enter / 主发送；`delivery=steer` |
| **Queue** | 当前回合完整结束后再开新回合 | Ctrl/Cmd+Enter（桌面）/「排队」钮（手机）；`delivery=queue` |
| **Stop** | 硬打断 | 主槽停止（与发送解耦；**否决**发送默认=Stop&send） |

| 决策 | 取值 |
|---|---|
| 请求体 | `delivery: "steer" \| "queue"` **必填**；缺 → 422；**否决**缺省回落旧自动分流（开发期无兼容层） |
| 空闲 | 开新回合；客户端仍带 `delivery=steer` |
| 热挂起 | `approval` / `delegation_authorization` / 用户侧 `escalation`（`awaiting==ceo` 除外）→ **409**；Steer/Queue 均不可绕 |
| 协调活跃 + steer | 现 `user_interjection` → CEO；CEO 可智能升格为排队（仅 Steer 路径） |
| 协调活跃 + queue | **强制** FIFO（绕过 CEO 插话） |
| 经典 in-flight + queue | 现 `turn_queued` FIFO，同连接续流 |
| 经典 in-flight + steer | ✅ ReAct/工具步边界真注入（EPHEMERAL `turn_steer_accepted`）；无 accepting 窗口 → 回落 queue（`degraded_from=steer`）；收口 leftover 升队时若有 live sink 再发 `turn_queued.degraded_from=steer`（否决伪装已插入） |
| 排队取消 | ✅ 按 `queue_id`（`POST …/queued-turns/{id}/cancel` + EPHEMERAL `turn_queue_cancelled`）；Stop/abort **≠** 取消排队 |
| 队列耐久 | 进程内；重启丢队（轻提示）；**否决**本切片做 durable queue |
| 展示 | Queue → 主时间线用户气泡 + 排队轻态；协调 Steer → 插话四态；经典 Steer → toast「已插入，下一工具步生效」 |
| 辩论掌舵 | 仍走独立 `/debate-steer`；与主框共用语言、**不**强制并控件 |
| UX 默认 | ✅ 空闲/生成中默认 `steer`；强制 `queue` 靠修饰键/显式钮；**否决**伪装「已插入」（失败才 degraded toast） |

### 已知行为（真跑 · 平台 DeepSeek · 2026-08）

以下为**已验证、按现状接受**的语义（非缺陷清单；若要改须另定案，禁顺手补丁）：

| 情境 | 实际行为 |
|---|---|
| 单轮散文（无后续 ReAct/工具步） | 仍可立刻 `turn_steer_accepted`；若本回合再无步顶可 drain → 收口 **leftover 升队**，live sink 再发 `turn_queued.degraded_from=steer`（诚实纠正）；用户补充常落在**下一回合** |
| 多轮 / 有工具步 | pending 在下一轮步顶 `drain` → `engine.turn_steer_inject`，**同回合**消化（真跑已见注入标记进同一条助手回复） |
| Stop 与排队 | Stop **不清** FIFO；当前回合结束后 **立即 drain** 下一项——此时按项 cancel 常已 404（项已开跑），属「不清队但会开跑」，**不是**「Stop 后冻结队列」 |

探针（维护者）：`apps/server/scripts/probe_delivery_steer_live.py`（`--suite all`）。

现状：P0+P1 ✅；P2（账户默认 Steer/Queue、辩论文案对齐、队列重排）**未做、可选**。→ 见代码：`messages.py` · `runtime/turn_steer.py` · `runtime/engine/loop.py` · 桌面 `composerDelivery.ts` · 手机 `messageDelivery.ts`

## Turn Journal（唯一事实源）

执行事实与展示事件共用**单一有序日志**；**否决**执行流/展示流分家再归并。

| 决策 | 取值 |
|---|---|
| 落盘 | Append-on-Emit：SSE 送达前先落盘；writer 单消费者 write-behind；owner 终了前必 `flush` |
| process 车道 | 语义边界步落盘（非 per-token）；纯散文回合不扩 `process_*` |
| 流式投影 | token 不进 journal → `turn_stream_state` UPSERT；终态删 |
| seq | live 由 DB 原子分配；merge 保留显式 seq；**否决**无锁 MAX+1 / 主键改 ULID |
| settlement | 同 write-behind 插队必达；dedupe 键须携完整事件 kind |
| 暂停态 | 新增回合内累积态须声明挂起归宿与再水化点（`turn_paused`） |
| 审计 | `agent_audit_events` = 下游只读投影，**非第二事实源** |

投影入口：`TurnState.from_journal`；恢复原语：`recover_turn`（恢复前先 orphan 热路 pending）。

## Run（唯一执行单元）

执行形状是数据（`depends_on`），不是离散模式。辩论/审查 = 主持人确定性循环驱动普通 DAG（**非独立 kind / 无 Arena**）。

| 决策 | 取值 |
|---|---|
| CEO | 根 Run 节点（CAPTAIN）；**否决** `synthesis` 零成本伪 run |
| 嵌套 | `depth ≤ 2` 硬上限；depth=2 永不获 `delegate`；单 lead 扇出 ≤4 |
| RunSession | transcript 可恢复延伸；续派接缝见 [多轮编排与同人续派](/docs/03-AI核心/多轮编排与同人续派.md) |

## 引擎纯化与端口

- 效应模型 `Continue | Handoff | Interact`；显式 `ToolContext`；按能力位非工具名特判。
- 宿主端口契约镜像 `runtime/ports.py`（Journal / EventSink / ClientRequestBridge / ConversationStore 已端口化）。
- **一轮一网关**：Turn 最早解析 `effective_gateway`，整棵委派树同一把，防 split-brain。

⏳：Redis 租约与事件总线；写类工具幂等键；大正文卸 ArtifactStore。
