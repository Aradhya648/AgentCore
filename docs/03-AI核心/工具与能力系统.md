## 一、Tool / Skill / Rule 边界

| | Tool | Skill | Rule |
|---|---|---|---|
| 是什么 | 副作用 / 读写 / 需审计 | HOW 教法（按名拉取） | 行为约束（进 `<rules>`） |
| 装配 | 声明式 `ToolRegistration` → registry | 系统 Skill 常备目录；市场 Skill ⏳ 绑定后进集 | Document `role=rule`（见 [记忆系统](/docs/03-AI核心/Agent记忆与知识系统.md)） |
| 注入 | LLM function calling | ≤阈值全文；超阈值 = 目录 + `consult_skill` | always / on_demand |

**单源**：经统一 `AgentEntityBinding` 绑到 Agent（能力域 ⏳；MVP 固定注册内置工具）。运行时只读「本地侧」，不碰市场侧。Skill 永不自动注入工具（仅 `suggested_tools`）；系统 vs 市场 = 两类来源、同一 `SkillRegistry` + `consult_skill`。

**表达形态 ≠ 工具**：mermaid / markmap / vega-lite = 直写代码块 + 前端渲染；需持久可编 → 创作产物。

**协议**：MVP = 内部 `Tool` Protocol + OpenAI FC；**MCP Client** ✅（→ [§四C](#四c本机-mcp-client)）。审批 `never`/`grantable` → [安全 §三](/docs/05-平台与运维/安全权限与治理.md)。CEO/worker 分集 → [执行引擎 §五](/docs/03-AI核心/执行引擎架构设计.md)。

→ 见代码：`tools/registration.py`、`runtime/skills.py`、`tools/catalog.py`

## 二、引用质量闸

`web_search` / `read_url` 双通道：**来源卡**（`citations_event` = 成稿实际引用）与**回合证据台账**（除 `blocked` 外全量登记）。档位单源 `citation_tier_for_url`——禁第二套分级器。

| 档位 | 来源卡 | 台账登记 |
|---|---|---|
| `blocked` | 出口剔除、永不挂卡 | **永不进** |
| `weak` | 仅成稿 `#rN` 引用时挂卡 + 弱源徽标 | 登记宽、`citable=true` |
| `official` / `media` / `unknown` | 同上 | 登记宽 |

- **登记仍宽 / 成稿闸窄**：台账除 `blocked` 外均可登记；成稿 `#rN` 闸 = `deep_read ∪ selected`（对齐辩论 `commit_research` 精神）。search-only 不得进成稿闸；`finish_guard` / settle reconcile 用 draft 子集，不用全量 `citable_ids()`。
- **`selected`**：settle 时正文实际引用且已 `deep_read` 的 id 持久标 selected；跨回合 hydrate 保留。可选 `doc_kind`（登记时可写；否则 title/snippet 启发式）。
- **书目形态闸**：正文以学位论文/期刊式著录绑定 `#rN` 时该 id 须 deep_read；元数据呈开题/答辩/公告类 → 回炉（禁域名黑名单）。无 `#rN` 绑定的 GB/T `[D]`/`[J]` 著录亦回炉。台账接通时，**worker 合同闸**对内容类落盘文件复用同一套 `citation_quality_reworks`（与 `finish_guard` 同源）；调研 `research/*.md` 遇未绑定书目时不再文末补脚注装锚。
- **调研两阶段引用**：`citation_mode=two_phase`（playbook/CEO 盖戳），或落盘/声明路径在 `AgentCore/文档/research/` / `AgentCore/文档/reviews/` → 阶段 A 草案**不**跑成稿引用闸；同 worker 升 B 后再验；`immediate` 显式退出。draft 不进 `delivery_status.artifacts` 主清单。→ 见代码：`runtime/runs/research_quality.py:is_two_phase_citation_deliverable`
- **跨回合 hydrate**：新回合 `#r` 台账从历史 assistant `evidence_ledger` 合并进引擎核；LLM history 可不带 ledger 全文。
- `search_policy`：per-run 结构化信号（禁 prompt 触发）；`debate_evidence` 额外硬剔 weak / 商城词典等。
- 前置：query 词数/CJK 加权上限（超限可机械规范化并明示；无法规范化才拒）；CJK 查询剔无 CJK 命中；缓存键 casefold + 拉丁词序归一。
- 名单无真实分布依据——以合成样本校准（目前无真实数据，以下为假设）。

→ 见代码：`runtime/citations.py`、`runtime/evidence_ledger.py`、`tools/builtin/web/`

## 三、沙箱

代码执行：subprocess + `SandboxProvider`；云端 gVisor（`GVISOR_ENABLED`，默认关）已生产化——禁网默认、产物 copy-in/out；sidecar 保留 subprocess。→ [安全 §五](/docs/05-平台与运维/安全权限与治理.md)、[部署与运维](/docs/05-平台与运维/部署与运维.md)

`browser_*`：统一 BrowserSession——工具名不变、仍 **worker-only**；宿主 **桌面** Local（CDP / DesktopBrowserBridge）\| Sandbox（云端 gVisor）；**Web / 无 Electron → 仅 Sandbox**（地址栏 create+navigate，拒本机 localhost）。AI 永不经手密码（password 硬拒 → `escalate(browser_login=true)`）。

**打开本会话 HTML 站点（定案 · 甲 + 乙降级）**：桌面 Local 上 `browser_navigate` 支持 workspace 相对 HTML 路径，走与用户产物「完整预览」同源的 `workspace://`（该对话的 workspace partition；URL host 须等于 partition 绑定 cid）；打开后可继续 click/type/snapshot。公网 URL 仍走该对话的 web partition（按 `conversation_id` 切开，不与其它对话共享 cookie）。Sandbox / 无 Bridge → 相对路径诚实失败（引导点产物完整预览），禁止假成功。→ 见代码：`tools/builtin/browser.py` · 桌面 `browser/host.ts`；产品蓝图 → [前端技术 §9.12](/docs/04-前端/前端技术与架构.md)

### 执行三分（短 / 有界验证 / 长驻）

| 面 | 工具 | 用途 |
|---|---|---|
| 短执行 | `code_execute` | 会很快自行退出的内联代码 / 短命令；硬顶仍短（≤60s）；同会话多 worker 的 `code_execute` 串行排队（`test_run` / `terminal` 不在此锁内） |
| 有界项目验证 | `test_run` | 项目 check（test / typecheck / build / 显式 verify 命令）；分钟级预算、可流式；超预算 = 验证未完成（`contract_failure`），不进「工具坏了」熔断 |
| 长驻 | `terminal` | 开发服务器等永不退出进程；`long_running` 分流保持；**CEO+worker**（仅 `location=local`）；schema `NEVER`，`start` 运行时升审批；CEO 限纯启/停/读，改码仍 delegate |

`completion_criteria=code_verified` / `verify_command` **默认走** `test_run`。项目级慢命令（`npm/pnpm/yarn install|test|build`、`tsc`、`pytest`/`vitest`/`jest` 等）进 `code_execute` → **硬拒**并改道 `test_run`（与长驻改 `terminal` 同构；`contract_failure`，不进工具熔断）。真短脚本仍走 `code_execute`（≤60s）。云端沙箱 / GRANTABLE 与 `code_execute` 同级治理（`code_execution_enabled_for`）。

写工具 miss 回执分角色：CEO 面 → 须 `delegate`；worker 因 `form=prose` 未授写盘 → 说明仅文字、请改形态 / escalate，**不**说「请用 delegate」。prose worker 的进度催促不要求 `str_replace`。→ 见代码：`tools/builtin/test_run.py` · `code_execute.py` · `project_verify.py` · `runtime/engine/tool_exec.py`

**长文落盘（✅）**：成篇交付默认短骨架 + 按节 `file_append` / `str_replace`；超长成篇**建议分段、不硬拒**整篇一次 `file_write` / `file_append` / `str_replace`（短文件仍可一次写）。写工具参数解析失败 → 过程线人话「改成分段继续」，模型回执保留技术细节并强制分段；连续失败**不**停用写文件。同 path 连续 ≥2 次同类写硬拒（成篇后禁 append / 代码结构完整性拒）→ 合流 `force_segmented`：收窄 `file_append`，保留 `file_write`/`str_replace`。CEO 识别用户粘贴的旧「参数不是合法 JSON」报错时禁教转义。→ 见代码：`tools/builtin/file_ops.py` · `runtime/engine/tool_exec.py` · `runtime/loop_controller.py`

**工作区 Office/PDF 读（✅）**：`file_read` 对 docx/pdf/pptx/odt/rtf **透明抽文本**（复用附件预解析核；读时默认不写 `*.md`）；xlsx/csv 等不抽、改 `code_execute`。扫描件给明确 notice，不做复杂 OCR。→ [双模式 §七](/docs/02-架构/双模式工作区.md)

**确定性导出 Word/PDF（✅）**：`md_to_docx` / `md_to_pdf` 把工作区 `.md` 导出为同目录同名 `.docx` / `.pdf`（共享 `docs_export`；PDF 引擎 fpdf2）。用户要「PDF / 可分享」时成文主路径 = 落盘 `.md` → `md_to_pdf` → handoff；**禁止**多份 HTML 顶替 PDF，**禁止** `code_execute`+reportlab 做主路径。云 = 本地同能力。→ 见代码：`docs_export/` · `tools/builtin/md_to_docx.py` · `tools/builtin/md_to_pdf.py`

**FILESYSTEM 容量合同 ≠ 活性超时（✅）**：字节/行/条目/Office 抽取成本触顶 → 早失败 `contract_failure` + 可执行下一步（不计工具熔断累计）。墙钟只表示通道/协程**活性挂起**（文案禁原样重试；仍计熔断，steer 强调缩小范围/换策略）。云 `ServerWorkspace` 整读上限与桌面 Local `WORKSPACE_READ_MAX=5MiB` 对齐。Local 通道 deadline **由外层工具活性预算派生**（非第二套独立 60s）；`timeout_ms` 下发桌面 AbortSignal，迟到 settle 仍 stale no-op。首活性超时 → 通道 sticky **dead**（同通道 inflight 失败信封收口 + 后续 op fail-fast，防连环 60s）。通道有界并发（默认 2）：仅约束 Local `WorkspaceChannel` 同时 await 桌面的 op；超额排队（计入外层墙钟），dead 后排队者拿槽即 fail-fast——云盘/`workspace_lock` 不动。→ 见代码：`workspace/limits.py` · `workspace/channel.py` · `runtime/tool_deadline.py` · `runtime/engine/tool_exec.py`

## 四B、本机 Host（第三能力面）✅ P0–P2 · P3 `host_shell`

> 与 Workspace / Browser 正交：结构化观测本机 OS、打开系统面板、受控动作，以及 Cursor 同款本机通用命令。详细定案在维护者本地；此处只留已确认契约。

| 项 | 契约 |
|---|---|
| 可用性 | 仅桌面 + 回填通道可达；与 folder/bind 正交（裸聊云 scratch 亦可） |
| 运输 | ClientTool / channel 回填（对标 external grant / `desktop_notify`）；**禁止**以 DesktopBrowserBridge loopback 冒充云可达。`DesktopClientChannel` 在 `desktop_online` 时装配（含云 backend） |
| 工具类 | 独立 `host_class`；**不**挂 `execution_class`；L2/L3/`host_shell` **不**吃 kickoff/`command=auto` 静默授 |
| 分工 | CEO：L1（`never`）+ **GRANTABLE 唯一例外** `host_shell`（`grantable`）；另持本地 `terminal`（非 Host 面、非 GRANTABLE schema）；L2/L3 仅 worker（**不**因 P3 自动给 CEO） |
| 权限 | PermissionAxes `host`：`off`/`ask`/`session` → [安全 §三](/docs/05-平台与运维/安全权限与治理.md) |
| P0 | `host_ping` · `host_info` · `host_audio_devices` · worker `host_open_settings(sound)` · 能力行 `host=` · 改写云 `reach_line` |
| P1 | L1 `host_storage` · `host_power` · `host_network_summary` · `host_apps`（有界摘要）；L2 面板扩至 `sound|display|network|apps|about`；GRANTABLE 审计对齐 |
| P2 | L3 受控白名单（worker · GRANTABLE · host_class · 禁 execution_class / kickoff 静默授）：`host_audio_set_default`（须先经 `host_audio_devices` 观测）；`host_service_restart`（起步仅 `Audiosrv`）；禁注册表深写 / 关防火墙 / 任意 sc；CEO 永不持 L3 |
| P3 ✅ | `host_shell`：CEO+worker · GRANTABLE · host_class；参数 `command` + 可选 `timeout_seconds`（≤120）；P3 首版**无** `cwd`（默认 home/shell cwd）；Win PowerShell / Unix `$SHELL -lc`；毁灭性 + **长驻命令**启发式硬拒（dev server 等须改 `terminal`）；Computer Use 仍 ⏳（与 MCP 分项） |
| 否决 | 放宽工作区 cwd；单点音频特例工具；Web/手机假装已查本机 |

`<workspace_context>`：能力行加 `host=`；云 reach =「工作区在云；本机 Host 以 `host=` 为准」。

→ 见代码：`desktop/channel.py` · `tools/builtin/host.py` · `runtime/pipeline/prepare.py`

## 四C、本机 MCP Client ✅

> 桌面配置本地 stdio MCP Server，工具经现有 Tool 管线进 worker（审批 / Journal / SSE 同径）。不做 AgentCore 对外 MCP Server；不替换 builtin；Computer Use / 远程 SSE·HTTP MCP / 按项目绑定 = 另项。

| 项 | 契约 |
|---|---|
| 运输 | **仅 stdio**；桌面主进程用官方 `@modelcontextprotocol/sdk`（`Client` + `StdioClientTransport`）拉起；回填对标 Host/`DesktopClientChannel`（`mcp_op_required` ClientTool）；**禁止**云端假连本机 stdio；Web/手机无「已接本地 MCP」假象 |
| 谁持有 | **默认仅 worker**；CEO 工具集不含 MCP |
| 审批 | MCP 工具一律 **`grantable`**（未知 Server 不得 `never`）；走**通用 Approval** 卡（挂起 / fulfill / 拒绝同径），不另开「信任 Server」轴；云工作区 + 桌面在线时 worker 仍须对 MCP/Host 弹卡（本机副作用） |
| 装配 | **账户/会话级**：用户启用的 Server → 本回合 worker 工具集（prepare/resume 经桌面 `list_tools` 发现）；不做按项目 / Agent 绑定 |
| 失败 | Server 未启 / 握手失败 / 崩溃 / stderr 诊断 → **降级为无该批工具**（错误明细含 stderr 尾 + 日志 + 能力行 `mcp=`），不阻断纯聊；**禁止**整段 ignore stderr |
| UX | 工具箱「集成 · 连接器」增删启停；手册「MCP（本机连接器）」 |

→ 见代码：`desktop/channel.py` · `tools/mcp/` · 桌面 `mcp-service.ts`（SDK）/ `mcpOps.ts` · `ConnectorsPage`

## 五、否决 / 待定

| 否决 | 理由 |
|---|---|
| 另造 `consult_capability` | 与 `consult_skill` 重复 |
