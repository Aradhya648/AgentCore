# hello-cli 固定 Prompt（S1 / 可衍生 S5）

请在**当前工作区**从零实现一个最小 Python CLI，包名建议 `hello_cli`：

1. `python -m hello_cli --help` 可运行。
2. `python -m hello_cli greet <name>` 打印 `Hello, <name>`。
3. `python -m hello_cli add <a> <b>` 打印两整数之和。
4. 补至少 1 个 pytest，并在工作区内跑通。

约束：只改本工作区；不要改工作区外的 AgentCore 产品代码；完成后简述创建了哪些文件。
