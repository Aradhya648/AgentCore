## 三、片头（~5 秒） ✅ 方案已确认

**策略：** 不做品牌宣传，直接用产品运行中的画面勾起观众兴趣（"结果闪现"）。

**制作方式：** Remotion 动画（复用现有 `apps/promo/` 工程管线）

**时间轴：**

| 时间 | 画面 | 动效 | 观众心理 |
|------|------|------|----------|
| 0–2s | 主区展示**多 Agent 协作图运行中全景**：多节点蓝边发光、DAG 层层展开、并行推进 | 从略微缩小→缓推至正常视角 | "这是什么？好多 AI 在同时干活？" |
| 2–3s | 右侧 SidePanel 滑出，展示 **Agent 运行详情**（某个节点的任务/思考/工具调用/输出） | SidePanel 从右侧滑入 | "每个 AI 的工作都能看到" |
| 3–4s | SidePanel 内容切换为 **CEO 最终汇总结果**（Markdown 结构化输出） | 内容淡入切换 | "结果还能自动汇总" |
| 4–5s | SidePanel 内容切换为 **指挥台「待你拍板」**（检查点/审批/升级决策界面） | 内容淡入切换 | "人还能参与决策？我想了解" |

**视觉参考：**
- 协作图全景 → 参考 `apps/promo/out/stills/appshell.png`（真桌面壳 + 11-Agent DAG）
- Agent 运行详情 → SidePanel 的 `RunDetailBody`（任务、思考、工具 IO、输出）
- CEO 汇总 → SidePanel 的 content tab（Markdown 正文）
- 指挥台 → SidePanel 的 command center tab（检查点/审批/升级）

**设计要点：**
- 使用产品真实暗色主题，不另做背景
- 协作图节点应有 running 状态（蓝边发光 + 流式预览光标）
- 侧面板三次内容切换要流畅自然，不突兀

## 六、视频内容大纲 ✅ 方案已确认

**核心策略：** 直接展示深度协作能力（产品独有差异点），不浪费时间演示其他产品已有的基础功能。

**形式：** 屏幕录制 + 人声解说

**结构：** 片头 → 3 个独立场景（各展示不同协作模式）→ 片尾

---

### 场景 1：多方辩论 → 人类拍板

| 项目 | 说明 |
|------|------|
| **用户输入** | "我收到两个offer，字节的资深工程师（80w）和一个AI创业公司的技术负责人（50w+期权），帮我分析下该选哪个" |
| **主要展示** | 圆桌辩论 + 人类检查点 + CEO 汇总 |
| **协作模式** | CEO 自行召集多顾问 Agent → 多方辩论交锋 → 修订对射 → 人类拍板做最终决策 → CEO 输出结论 |
| **为什么选这个任务** | 观众理解门槛极低（人人都有过选择困难）；辩论内容观众会跟着思考，注意力留存强 |
| **重点展示的产品能力** | 圆桌辩论可视化、Agent 观点交锋、修订 overlay、"待你拍板"检查点卡片、CEO 汇总输出 |

---

### 场景 2：并行生产 → 交叉审阅

| 项目 | 说明 |
|------|------|
| **用户输入** | "帮我做一个完整的自媒体启动方案，我想做AI领域的科普博主" |
| **主要展示** | DAG 扇出 + 并行执行 + 交叉修订/迭代 |
| **协作模式** | CEO 自行拆为多条并行线（账号定位/选题规划/视觉风格/变现路径）→ 多 Agent 同时产出 → 完成后互相审阅一致性（选题和定位是否匹配、风格和受众是否对齐）→ 修订迭代 → 合并最终方案 |
| **为什么选这个任务** | 很多人想做自媒体，共鸣强；产出物多样且具体；交叉审阅冲突自然（选题风格和目标受众不匹配时需要修订） |
| **重点展示的产品能力** | DAG 并行扇出、多节点同时 running、交叉修订箭头、迭代轮次、最终合并汇聚 |

---

### 场景 3：复杂编排 → 嵌套委派

| 项目 | 说明 |
|------|------|
| **用户输入** | "帮我做一份主流AI公司的深度分析，OpenAI、Google、Anthropic、Meta这些，技术路线、商业模式、用户规模、融资情况都要覆盖到" |
| **主要展示** | 嵌套委派 + 多层 DAG + 检查点 + 记忆沉淀 |
| **协作模式** | CEO 自行编排 → 每家公司分配一个调研组 → 各组再委派子任务（技术分析/商业模式/用户数据/融资情况）→ 中间可能触发检查点（如发现某公司刚有重大动态，是否纳入）→ 人决策 → 最终汇总横向对比 → 经验写入记忆 |
| **为什么选这个任务** | 目标观众（科技人群）极感兴趣；信息全公开无法律风险；多公司 × 多维度天然嵌套深、DAG 规模大视觉冲击强；检查点自然（分析中发现新动态需人确认） |
| **重点展示的产品能力** | 多层嵌套 DAG 可视化、Agent 再委派 Agent、动态检查点、DAG 规模感、记忆沉淀 |
